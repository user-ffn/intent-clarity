# Intent Clarity

**Tagline**: I got you.

> 通过诊断式提问帮用户澄清模糊需求，然后直接执行。

---

## 这是什么？

Intent Clarity 是一个 Claude Code 技能包，帮助那些"不知道怎么跟AI说"的用户。

**不是**帮你生成更好的 prompt，**而是**我来帮你理清你真正想要什么，然后直接开始干活。

---

## 为什么需要它？

很多人用 AI 时遇到的问题：
- ❌ "我想做点什么，但不知道做什么"
- ❌ "我想学AI，但不知道从哪开始"
- ❌ "我有个模糊的想法，但不知道怎么表达"

传统 AI 的回答：
- 🤖 "请明确你的需求"
- 🤖 "你可以这样问我..."
- 🤖 "我需要更多信息"

**Intent Clarity 的做法**：
- ✅ 通过2-5个问题，帮你想清楚
- ✅ 区分"已确认"和"推断"，不过度解释
- ✅ 澄清完直接执行，无缝衔接

---

## 工作原理

### 1. 快速澄清（需求明确时）

用户："帮我写一篇文章"

Intent Clarity：
- 判断：需求明确（行为清晰，缺细节）
- 问2-3个补充问题（主题/受众/格式）
- 确认理解
- **直接开始写文章**

### 2. 深度探索（需求不明确时）

用户："我想做点什么但不知道做什么"

Intent Clarity：
- 判断：需求不明确
- 状态诊断（无方向+有动力）
- 用"经历回忆"策略提问（4-5个问题）
- 逐步聚焦到具体方向
- **给出具体建议并开始执行**

## 使用

### 自动触发

当你的表达包含以下特征时，Intent Clarity 会自动启动：
- "不知道怎么说/表达/描述"
- "想做X但..."
- "迷茫/困惑/不知道"

### 手动调用

```
/intent-clarity 我想做点什么但不知道做什么
```

或简写：
```
/ic 帮我想想我适合做什么
```

## 示例

### 示例1：写文章（快速澄清）

```
你：帮我写一篇文章

Intent Clarity：
这篇文章的主题是什么？

你：介绍我做的基金筛选工具

Intent Clarity：
打算发在哪？给谁看？

你：小红书，给对基金感兴趣的小白

Intent Clarity：
你希望读者看完有什么感受？

你：觉得这个工具有用，想试试

Intent Clarity：
让我确认一下：

已确认：
- 你想写一篇文章介绍你的基金筛选工具
- 发在小红书，给对基金感兴趣的小白看
- 希望读者觉得有用，想试试

我推断：
- 文章风格要通俗易懂（针对小白）
- 重点是实用性和易用性

对吗？

你：对

Intent Clarity：
好，我现在开始写。

# 基金太难选？这个工具3分钟帮你找到靠谱基金

[完整文章...]
```

### 示例2：不知道做什么（深度探索）

```
你：我想做点什么，但不知道做什么

Intent Clarity：
过去有没有什么事情，你做的时候特别投入？

你：高中时帮同学做PPT挺开心的

Intent Clarity：
你觉得那时候为什么开心？

你：能帮到别人，而且做出来的东西好看

Intent Clarity：
有没有什么事情别人觉得麻烦，但你觉得挺有意思？

你：整理信息、排版、配色

Intent Clarity：
让我确认一下：

已确认：
- 你喜欢创造视觉化的内容
- 你对整理信息、排版有兴趣
- 你希望能帮助到别人

我推断：
- 你可能适合做内容创作/信息可视化相关的事
- 你重视"有用"和"好看"的结合

对吗？

你：对，有道理

Intent Clarity：
明白了，那我给你3个具体方向，你可以今天就开始试：

1. **AI辅助的信息可视化**
   [详细展开...]

2. **小红书/即刻的图文创作**
   [详细展开...]

3. **帮产品/项目做落地页设计**
   [详细展开...]

你觉得哪个最有意思？我可以详细展开。
```

## 设计原则

### 1. 不追求完全理解，追求"够用"
不会无限提问，够用就停（最多4-5个问题）。

### 2. 区分"已确认"和"推断"
在确认理解时，明确标注哪些是用户说的，哪些是AI猜的。

### 3. 无缝衔接，直接执行
澄清完不让你复制prompt去别的地方，直接开始干活。

### 4. 动态调整，不走死流程
根据你的回答实时调整，不是机械地问问题。

### 5. 保持温度，不要机械
对话，不是表单填空。

## 核心技术

- **需求明确度诊断**：行为+目标+场景三维判断
- **任务类型分类**：5种任务（信息/内容/路径/决策/设计）
- **状态检测**：二维模型（方向×行动）
- **动态问题生成**：根据任务类型和状态选择问题集
- **不确定性管理**：区分已确认信息和推断信息

## 为什么叫 Intent Clarity？

- **Intent**：意图，你真正想要什么
- **Clarity**：清晰化，帮你想清楚
- **I got you**：我懂你

从 "Prompt Clarity"（帮你生成更好的prompt）
到 "Intent Clarity"（帮你理清真正的意图）

这个改名体现了产品理念的升级：
- 旧版：工具视角（生成prompt）
- 新版：伙伴视角（理解你，帮你做）
