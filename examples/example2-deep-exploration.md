# 示例2：深度探索 - 完全迷茫

**场景**：用户不知道自己想做什么，需要深度探索

---

## 对话流程

### 用户输入
```
我想做点什么，但不知道做什么
```

---

### Intent Clarity 内部判断（不展示给用户）

```
【需求明确度诊断】
- 行为：❌ 没有具体行为
- 目标：❌ 不清楚
- 场景：❌ 不清楚
- 不明确信号：✅ "不知道做什么"
→ 判定：需求不明确

【状态诊断】
检测到的模式：无明确方向，但"想做"说明有动力
→ 状态：无方向+有动力
→ 策略：经历回忆（从过去经历中找线索）
```

---

### Intent Clarity
```
我理解你想探索一下方向。让我问几个问题帮你想清楚：

过去有没有什么事情，你做的时候特别投入？
```

### 用户
```
高中时帮同学做PPT挺开心的
```

---

### Intent Clarity 内部判断
```
【信息提取】
已确认：喜欢做PPT
待挖掘：为什么开心？（挖掘动机）
```

---

### Intent Clarity
```
你觉得那时候为什么开心？
```

### 用户
```
能帮到别人，而且做出来的东西好看
```

---

### Intent Clarity 内部判断
```
【信息提取】
已确认：
- 喜欢帮助别人
- 喜欢创造视觉化的东西
待挖掘：具体擅长什么？
```

---

### Intent Clarity
```
有没有什么事情别人觉得麻烦，但你觉得挺有意思？
```

### 用户
```
整理信息、排版、配色
```

---

### Intent Clarity 内部判断
```
【信息汇总】
已确认：
- 喜欢帮助别人
- 喜欢创造视觉化内容

推断：
- 可能适合内容创作/信息可视化
- 重视"有用"+"好看"的结合

【清晰度检查】
核心信息已足够，可以给出方向了（3个问题）
→ 停止提问，开始确认
```

---

### Intent Clarity
```
让我确认一下：

**已确认**：
- 你喜欢创造视觉化的内容
- 你对整理信息、排版有兴趣
- 你希望能帮助到别人

**我推断**：
- 你可能适合做内容创作/信息可视化相关的事
- 你重视"有用"和"好看"的结合

我理解对吗？
```

### 用户
```

```

### Intent Clarity（直接执行）
```
明白了，那我给你3个具体方向，你可以今天就开始试：

## 1. AI辅助的信息可视化

**做什么**：
用AI工具把复杂数据变成好看的图表、海报、信息图。

**为什么适合你**：
- 结合你的审美能力（排版、配色）
- 帮别人"看懂数据"，有实用价值
- AI降低技术门槛，你专注设计

**今天就能做的小项目**：
找一份公开数据（比如你的基金收益、健身记录），用Claude + Figma/Canva做成一张可视化海报。

**学习路径**：
- 第1周：学会用Figma基础操作
- 第2周：学会用Claude生成图表数据
- 第3周：做10张不同主题的信息图
- 第4周：发到小红书/即刻，看反馈

**可能的变现**：
帮自媒体/小企业做数据可视化（500-2000元/张）

---

## 2. 小红书/即刻的图文创作

**做什么**：
做"XX知识卡片"系列，用好看的排版呈现有用的知识。

**为什么适合你**：
- 你擅长整理信息（把复杂的讲简单）
- 你有审美（卡片做得好看）
- 帮助别人学知识，有价值感

**今天就能做的小项目**：
选一个你了解的领域（基金/健身/职场/学习方法），做3张知识卡片发小红书。

**学习路径**：
- 第1周：研究小红书爆款卡片的规律
- 第2周：固定一个模板，做20张卡片
- 第3周：分析数据，找到你的优势领域
- 第4周：持续输出，积累粉丝

**可能的变现**：
- 接广告（5000粉起，单条500-2000元）
- 卖知识付费课程/资料包
- 帮品牌做图文内容

## 3. 帮产品/项目做落地页设计

**做什么**：
很多开发者/创业者会写代码但不会设计，你帮他们把产品"包装"得好看又清晰。

**为什么适合你**：
- 你擅长整理信息（把复杂功能讲清楚）
- 你有审美（页面做得好看）
- 直接帮到创业者，有成就感

**今天就能做的小项目**：
去Product Hunt找一个有意思但首页很丑的项目，用Figma重新设计首页，发给作者。

**学习路径**：
- 第1周：研究10个优秀落地页的结构
- 第2周：用Figma重新设计3个真实项目
- 第3周：主动联系5个开发者，免费帮他们改
- 第4周：收集作品集，开始接付费单

**可能的变现**：
- 落地页设计：2000-5000元/页
- 如果会写代码实现：5000-10000元/页

## 我的建议

从**第2个**（小红书图文）开始，因为：
- ✅ 门槛最低（今天就能做）
- ✅ 反馈最快（几小时就能看到数据）
- ✅ 最容易坚持（每天做1张卡片，30天见效）

做1个月后，如果：
- 你发现自己更喜欢"美化数据" → 转第1个方向
- 你发现自己更喜欢"帮产品设计" → 转第3个方向

---

你觉得哪个最有意思？或者你还有什么顾虑？我可以详细展开。
```

---

## 关键点

1. **只问了3个问题**，没有无限挖掘
2. **从过去经历入手**，而不是问"你想做什么"（用户说了不知道）
3. **逐步聚焦**：做PPT → 为什么开心 → 具体擅长什么
4. **区分了确认和推断**，不过度解释用户
5. **给出3个具体方向**，每个都有：
   - 做什么
   - 为什么适合
   - 今天就能做的小项目
   - 学习路径
   - 变现可能
6. **推荐了最容易开始的**，降低行动门槛
7. **总耗时约5分钟**，符合深度探索的定位
8. **最后不是结束，是开放式追问**，如果用户还有疑问可以继续
